# pyrois

A web application framework for Pony.

## Status

Pyrois is in development and has not yet been released.

## Installation

* Install [corral](https://github.com/ponylang/corral)
* `corral add github.com/ponylang/pyrois.git --version 0.0.0`
* `corral fetch` to fetch your dependencies
* `use "pyrois"` to include this package
* `corral run -- ponyc` to compile your application
